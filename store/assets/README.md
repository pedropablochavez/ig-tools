# Store image files

- `promo-440x280.png`: original promotional artwork, 440 × 280 pixels.
- `screenshot-music-1280x800.png`: actual bundled audio credits / playback / download controls on a
  fictional sample feed, clearly marked as an illustrative demo.
- `screenshot-profile-1280x800.png`: actual bundled full-size profile viewer on original sample art,
  clearly marked as an illustrative demo.
- Extension icon: `../../icons/icon128.png` (128 × 128, also included in the upload ZIP).

No real accounts, private posts, faces or third-party photos are used. Inspect these images before
submission; Google decides whether supplied listing assets meet its current review requirements.
Regenerate with `python scripts/prepare_store_assets.py --browser <path-to-Chromium-browser>`.
